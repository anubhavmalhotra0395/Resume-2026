AI-Powered Vocal Processing Tool

Built an AI-based application that takes a reference song and automatically applies similar sound effects (EQ, reverb, compression, autotune) to another vocal track.

What it does:

  • Compares two audio tracks

  • Returns a processed version with explanation

Why it matters:
